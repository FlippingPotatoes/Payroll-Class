# Payroll Class Demonstration
A small school project to create a set of 7 employees and display their internal values.

Features user prompting, input handling, and writing that all to an array for 7 employees.
Inputs are the employees rate and hours work, then calculates and stores the total pay for that employee.
Reads out and later displays that data in a table format.
